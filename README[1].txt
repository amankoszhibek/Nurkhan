TIGERS TEAM — готовый статический сайт.

Откройте index.html в браузере.
Для Netlify: перетащите папку tigers_team_site в Netlify Drop (или загрузите ZIP через Deploy manually, если доступно).
Для GitHub Pages: поместите index.html, styles.css, script.js и assets в корень публикуемой ветки.
Расписание редактируется в script.js в объекте schedule.
Все изображения и видео извлечены из переданного оригинального HTML.
Номер WhatsApp и Instagram взяты из исходного сайта.
